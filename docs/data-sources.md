## 선택 이유와 주의점

### 병원

HIRA ZIP 안의 병원정보와 진료과목 XLSX는 암호화된 요양기관 ID로 연결됩니다. 파일 적재 시
`시도코드명=경북`이고 좌표가 있는 기관만 보관합니다. 검색 결과는 “가까운 의료기관”을 뜻하며
당일 진료 가능 시간이나 예약 가능성을 보장하지 않습니다.

### 버스

전국 정류장 파일과 포항 노선 파일은 정규화한 정류장명으로 연결하며, 현재 고유 정류장명 기준
97.7%가 일치합니다. 포항 노선 CSV의 `운행시간`은 배차 횟수가 아니라 노선 소요시간이므로
횟수 계산에 사용하지 않습니다.

별도 포항시 공식 시간표의 첫차·막차와 최대 배차간격으로 간선 일 운행횟수의 보수적 하한을
계산합니다. 이미지형 지선 PDF 13개는 원본 그대로 보관하고, 사람이 확인한 정확한
`(노선명, 노선상세)`별 게시 횟수를 검수 CSV로 관리합니다. 빌드·런타임에 OCR을 두지 않습니다.

정류장별 지선 횟수는 그 정류장을 실제 포함하는 패턴만 합산하며 같은 패턴 안의 반복 정류장은
한 번만 셉니다. 이 방식으로 53개 노선 중 51개를 판정합니다. 안정적인 고정 시간표가 없는
`임시노선`과 호출형 `죽장DRT`는 미상이고, 장날·CALL·임시·요청 운행은 기본 횟수에서
제외합니다. 한국교통안전공단의 2026-07 버스노선·시간표 파일도 검토했지만 관할 목록에
포항시가 없어 포항 배차 근거로 사용하지 않았습니다.

### 인구

행정안전부 전체 읍면동 연령별 주민등록인구 CSV의 경상북도 행을 적재합니다. 행정구역명 끝의
10자리 코드를 분리하고 10세 구간별 인구와 총인구를 보관해 비율을 계산합니다. 현재 기준월은
2026년 7월입니다.

### 치안

동네 단위 범죄 건수 공개는 제한적이고 비교 왜곡 위험이 있으므로 HWPX의 시도·시군별 6개
분야 지역안전등급을 적재합니다. 2025년 등급은 2024년 안전통계로 산출되었고, 1등급이 동일
행정단위 그룹 안에서 상대적으로 안전합니다. 이는 절대 범죄율이나 개별 주소의 안전도를
뜻하지 않습니다.

### 시장

표준데이터는 법령·조례에 따라 인정된 전통시장을 제공해 “시장 가까움”을 일관되게 판정할 수
있습니다. 비등록 상권·마트·편의점은 누락됩니다.

### 상가업소

상가(상권)정보 전국 ZIP의 경북 CSV에서 영업 중인 업소 144,967곳을 적재합니다. 상호·지점명,
3단계 상권업종분류, 표준산업분류, 주소와 좌표를 제공하며 전화번호와 영업시간은 포함하지
않습니다. 상가업소번호는 분류 개편 시 변경될 수 있어 장기 불변 식별자로 해석하지 않습니다.

## 파일 수명주기

원본은 `data/raw/`에 두고 `make data`가 경북 행만 추출해 SQLite를 원자적으로 교체합니다.
원본 PDF와 DB는 용량 때문에 Git에서 제외하고, 출처·PDF 페이지·검수 메모가 명시된 작은
배차 보조표만 커밋합니다.
빌드 시 각 원본의 SHA-256을 DB `metadata` 테이블에 기록합니다. 런타임은 네트워크를 사용하지
않으며 `DATA_MODE=api`를 명시한 경우에만 기존 API 클라이언트를 사용합니다.
