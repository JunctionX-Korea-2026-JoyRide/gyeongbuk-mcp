# 실제 코드 구현 계획

## 목표 질의

`차 없는 70대가 살기 좋은 포항 근처 동네`를 병원 접근성, 버스 운행량, 시장 접근성으로
1차 선별하고, 이후 고령인구 비율과 시군구 안전등급을 보조 정보로 제공한다.

## 완료: 파일 기반 접근성 도구

- `src/clients/local_data.py`: SQLite 기반 HIRA·버스·시장·인구·안전지수 클라이언트
- `src/services/snapshot_builder.py`: ZIP/XLSX/CSV/HWPX 검증, 경북 필터, 정규화, 체크섬 기록,
  원자적 DB 교체
- `scripts/build_snapshot.py`, `make data`: 재현 가능한 적재 명령
- `src/services/geo.py`: Haversine 거리와 보행시간 환산
- `src/services/accessibility.py`: 병원·정류장·시장 검색과 정규화
- `src/services/recommendations.py`: 시장 중심 후보 생성, 필수 조건, 100점 랭킹
- `src/tools/`: 구조화된 FastMCP 도구 6개와 입력 검증
- `data/reference/pohang_bus_frequencies.csv`: 포항시 공식 시간표를 구조화한 보조표
- `data/reference/pohang_branch_pattern_frequencies.csv`: 지선 PDF를 정확한 노선 변형에
  연결한 검수표
- `tests/`: API 파서와 파일 클라이언트, 오류, 배차 계산, 거리 필터, 추천, 도구 등록 검증

기본 `DATA_MODE=file`에서는 인증키나 외부 연결 없이 여섯 도구가 동작합니다. DB가 없으면
`make data`를 실행하라는 안전한 오류를 반환합니다. `DATA_MODE=api`는 비교·비상용으로 남겨
두었습니다.

현재 실제 적재 결과:

- 경북 병의원 3,415곳, 진료과목 16,031건
- 경북 정류장 29,735곳
- 포항 노선 53개, 정류장–노선 연결 5,656건
- 포항 노선 패턴 196개, 패턴–정류장 연결 20,393건
- 배차 판정 가능한 포항 노선 51개(간선 22개, 지선 29개)
- 경북 전통시장 132곳
- 경북 행정구역·연령 구간 3,949건
- 경북 시도·시군·6개 분야 지역안전등급 138건

## 다음: 파일 갱신 자동화와 운영 안정화

1. 기대 파일의 기준일·크기·체크섬을 manifest 형식으로 사전 검증한다.
2. 새 파일의 열 추가·삭제를 감지하고 이전 DB를 보존하는 배포 작업을 만든다.
3. 포항 좌표 3~5곳의 기대 병원·시장·정류장을 스냅샷 회귀 테스트로 고정한다.
4. 동일 정류장명이 멀리 떨어진 곳에 중복될 때 노선 순서와 좌표로 연결 정확도를 개선한다.
5. 지선 PDF 변경을 감지하는 체크섬 manifest와 검수 알림을 추가한다.
6. 데이터 기준일이 허용 기간보다 오래되면 도구 경고에 자동으로 표시한다.

완료 기준:

- 새 파일 스키마가 다르면 기존 DB를 훼손하지 않고 빌드 실패
- 동일 원본에서 같은 행 수와 결정적인 검색 결과 확인
- 포항 실제 좌표 스모크 테스트와 `make check` 통과

## 완료: 연령대별 인구 비율 도구

구현 파일:

```text
src/services/demographics.py
src/models/demographics.py
src/tools/demographics.py
tests/test_local_data.py
docs/tools/get-age-population-ratio.md
```

1. 행정안전부 전체 읍면동 연령별 주민등록인구 CSV를 원본으로 보관한다.
2. 행정구역명에서 10자리 코드를 분리하고 경북 행의 10세 구간을 SQLite에 적재한다.
3. `get_age_population_ratio(region, age_from, age_to, as_of)`를 구현한다.
4. 해당 연령 인구 합계, 전체 인구, 비율과 기준년월을 반환한다.
5. 기본 70대는 70~79세이며 원본 구간을 자르는 요청은 명시적 오류로 처리한다.
6. 최신월 선택, 구간 불일치, 모호한 지역명과 0명 분모를 서비스 계층에서 처리한다.

추천 결과와의 자동 결합은 좌표-행정구역 매핑 뒤에 추가합니다. 비율이 높다는 사실만으로
살기 좋다고 단정할 수 없기 때문에 설명용 보조 지표로만 사용합니다.

## 완료: 치안 정보 도구

구현 파일:

```text
src/services/safety.py
src/models/safety.py
src/tools/safety.py
tests/test_local_data.py
docs/tools/get-safety-grade.md
```

1. 행정안전부 지역안전지수 HWPX 표에서 경북 시도·시군별 6개 분야 등급을 정규화한다.
2. 공표연도와 통계 기준연도를 별도 필드로 저장한다.
3. `get_safety_grade(region, category="crime", publication_year=None)`를 구현한다.
4. 1등급이 상대적으로 안전하다는 방향과 비교 집단을 결과에 포함한다.
5. 공표 HWPX를 원본 그대로 보관하고 빌드 시 체크섬을 기록한다.
6. 누락·모호한 지역명과 최신연도 선택을 명시적으로 처리한다.

“범죄율”이라는 이름으로 등급을 반환하지 않습니다. 절대 발생률이 아니라 상대 등급임을
도구명과 필드명에서 명확히 합니다.

## 좌표와 행정구역 결합

시장 대표 좌표를 행정동·시군구 코드로 변환하는 로컬 공간 매핑을 추가합니다. 이 단계가
끝나야 시장 중심 후보에 읍면동 인구와 시군구 안전등급을 정확히 결합할 수 있습니다.

최종 추천 결과에는 행정동·시군구, 70~79세 인구 비율과 기준년월, 범죄 분야 안전등급과
기준연도, 지표마다 공간 단위가 다르다는 경고를 추가합니다.

## 고령자 보행 품질 개선

직선거리 추정을 도보 경로 데이터로 교체하거나 병행하고, 경사·횡단보도·보도 단절·저상버스
정보를 확보할 수 있을 때 별도 점수로 추가합니다. 기존 결과 계약의 `is_estimated`와
`estimation_method`는 유지합니다.

## 우선순위와 의사결정

1. 포항 지선 PDF 13개와 검수 CSV를 패턴 단위로 적재했습니다. 53개 중 51개 노선을
   판정하고 `임시노선`, `죽장DRT`는 미상으로 유지합니다.
2. 도보 경로를 붙이기 전에는 “15분 이내” 대신 “보행 추정 15분 이내”라고 표현합니다.
3. 연령·치안은 공간 단위 결합 후 설명용 보조 지표로 추가합니다.
4. 범죄 관련 세부 좌표나 사건정보를 추정·합성하지 않고 공식 공표 단위만 제공합니다.
